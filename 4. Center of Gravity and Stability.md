## 4.2 CG Calculation — Initial Error and Correction

Calculation of CG in Static condition 

Given:

Human weight = 100kg

Assembled frame = 
| Weight | Component |
| ----- | ----- |
| 14kg | Frame |
| 14kg | Battery |
| 30kg | Wheel + HubMotor |
| 5kg | Electronic |

Assembled Total = 63 ~ 65kg   

### Now Load Calculation : .... Per wheel 

F = $$\frac{Total Weight * g }{2}$$

F = $$\frac{165 * 9.81}{2}$$ = 809.325 N

### 1. Bending moment on axle 

30mm distance for torque plate to bearing 

M = F * D = 809.325 * 0.03 = 24.27 N.m

### 2. Section modulus of the axle (D = 12mm )
nen
z = $$\frac{\phi * D^3}{32}$$ 

z = $$\frac{\phi * 0.012^3}{32}$$ = $$1.696*10^-7 m^3$$

### 3. Bending stress

$$\sigma = \frac{M}{z}$$

$$\sigma = \frac{24.27}{1.696*10^-7}$$ = 143.1 MPa

### 4. Factor of safety 

$$FOS = \frac{Yield}{\sigma}$$

$$FOS = \frac{250}{143.1}$$ = 1.74 ~ 2

Hence 12mm axle can handle static load.

$$Hcg = \frac{30621.2}{165}$$
